Texture Atlas (2D)

One 1024×1024 image holds every face. The lines are the mesh triangles drawn at their UVs. Switch to UV checker: equal squares on the model mean no stretching, and the red corner marks (s,t) = (0,0) of each region.

Theory: Building the Models

Every model is made from 3 primitives: box 6 quads, each face mapped to a region cylinder side wraps t once around, caps map a disc cone cylinder with end radius 0 car body box + tapered cabin + 4 wheel cylinders building tower box + penthouse box ship hull box + bow wedge + cabin, bridge, funnel airplane fuselage cylinder + nose/tail cones, box wings, tail, fin + 2 engine cylinders Each face has its own 3 vertices, so normals are flat.

Theory: UV Atlas Regions

uv = ( (x0 + s·w) / 1024, (y0 + t·h) / 1024 ) (s,t) in 0..1 inside the region, from the face position: side: s = (x + 1.2) / 2.4 t = (0.55 - y) / 0.4 w/h of the region = width/height of the face in metres, so the texel density is the same everywhere.

Theory: Mirroring & Seams

Both sides use s from x, so they share one region (front stays front, text would read mirrored). Building: three walls share one facade region. Cylinders: t = segment / N wraps once around. The seam at t = 0 / 1 gets duplicate vertices.
